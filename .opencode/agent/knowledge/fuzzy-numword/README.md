retired `[incident:safe-form:esc]` escape) and the intercept_observer

redirect notes).

- What goes here: the PRIMER (`primer.md` — the short usage form, moved
  here from `research/fuzzy-numword/` on #100 with the escape section
  annotated REMOVED) + future distilled reference files of this track.
- What does NOT go here: the LARGE research records (the decision-record,
  specs, drafting — they stay in `research/fuzzy-numword/`), general
  plugin knowledge (`knowledge_plugins.md` / `knowledge_tools.md`),
  unverified findings (they wait in `knowledge_inbox.md`).
- Provenance rule: every file names its source (research area / session /
  date) so it can be re-verified instead of trusted by memory.
