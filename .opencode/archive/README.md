# archive/ — closed, frozen state (history, not instructions)

Purpose: the durable record of things that no longer act — `loop/` (finished
loopruns), `proposals/` (old proposal iterations + design drafts), `drafts/`.
Moved here = FROZEN: read for evidence, never edit, never treat as current
(current state = the NAP + `git log` + `TODO.md`). Phase closes move the NAP
here as `archive/<YYYY-MM-DD>-<slug>.md` with a STATUS header. Sub-folder
READMEs explain each area.
