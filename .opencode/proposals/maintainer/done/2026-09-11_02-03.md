- instruction for each looprunner, planner and worker on startup
  - append current date_time, session_id, agent_model (e.g planner_Q4_120K), START, and onliner of task in loop.log
- instruction for planner and looprunner on return of a sub-agent start:
  - append current date_time, session_id, agent_model, RETURN in loop.log
- instruction on task completion for every agent
  - append current date_time, session_id, agent_model, DONE, <CTX>%/<REM>K in loop.log

- loop.log located in the corresponding folder in .opencode/archive/autorun*

- base for looprunner and planner to keep track of what sessions are active and easy to implement via system prompt
  - doubles a bit the feature of the log of the handover plugin - lets see what is more useful
