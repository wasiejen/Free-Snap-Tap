# priority — what I want next (my ordering, top = first)

Numbered list; reorder = reprioritize, delete = no longer wanted. Entries may
name a TODO.md ID, a proposal file, or just a theme. The planner reads this at
session start and orders its planning by it (highest entry first when picking
the next task; tie-breaker between clear TODO candidates). This file is the
maintainer's — agents are read-only on it. Stale/unresolvable entries: the
planner notes the question in the NAP / asks; only the maintainer deletes.
